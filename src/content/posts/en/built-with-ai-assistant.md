A few weeks ago I built a personal AI assistant. Gave her an OpenClaw runtime, named her Charlotte (I was a *Charlotte's Web* fan 😁), and we started building things together.

First project we tackled: my personal website. I'd describe what I wanted, she'd write the code, I'd push back, she'd iterate. Astro, Tailwind, bilingual — built in a weekend.

Once the site was done, I figured: the content's all there. Why not turn it into something that moves?

So Charlotte built this — a Remotion video scripted from my site's structure. React-based, no timeline editor, no Premiere. Just code that compiles into motion.

Two hours. Start to finish.

**Tools:** OpenClaw · Astro · Remotion · Claude underneath it all
